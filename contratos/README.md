# Contratos — Lucas Designer Web

Templates de contratos para prestação de serviços de criação de sites.

## Como usar

1. **Briefing** — Preencha com o cliente antes de começar o projeto
2. **Contrato** — Preença com os dados acordados no briefing
3. **Autorização de Domínio** — Preencha quando for registrar domínio no Registro.br

## Fluxo de hospedagem

- **Domínio:** Registro.br (~R$40/ano)
- **Hospedagem:** GitHub Pages (gratuito)
- **DNS:** configurado no Registro.br apontando pro GitHub Pages

## Arquivos

- `briefing-projeto.md` — Questionário para coletar informações do cliente
- `contrato-criacao-de-sites.md` — Contrato de prestação de serviços
- `autorizacao-registro-dominio.md` — Autorização para registrar domínio no Registro.br

## Dicas

- Sempre tenha o contrato assinado **antes** de começar o projeto
- O domínio deve ser registrado **no nome do cliente**
- Guarde cópias de todos os documentos assinados
- Envie cópia ao cliente por e-mail
