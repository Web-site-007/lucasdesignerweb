# PROJECT BRIEF

## Visão Geral
Site institucional/landing page para venda de **criação de sites e serviços digitais**. O objetivo é converter visitantes em clientes através de uma presença profissional, depoimentos e CTA claro.

## Objetivos
- Apresentar os serviços oferecidos de forma clara e profissional
- Gerar leads qualificados (formulário de contato / WhatsApp)
- Demonstração de portfólio com trabalhos reais
- Credibilidade através de depoimentos e resultados

## Serviços a Vender
- Criação de sites (landing pages, sites institucionais, portfólios)
- Lojas virtuais / e-commerce
- Sistemas web sob demanda
- Aplicativos mobile
- Consultoria digital

## Público-Alvo
- Empreendedores que precisam de presença online
- Pequenas e médias empresas
- Profissionais autônomos (dentistas, advogados, restaurantes, etc.)
- Quem já tem site mas precisa de redesign

## Funcionalidades do Site
1. **Hero Section** — proposta de valor + CTA principal
2. **Serviços** — cards com descrição e preço (ou "sob consulta")
3. **Portfólio** — galeria de projetos realizados
4. **Depoimentos** — social proof
5. **Sobre** — quem é o responsável / equipe
6. **Contato** — formulário + WhatsApp + redes sociais
7. **FAQ** — perguntas frequentes

## Stack
- Frontend: HTML5, CSS3, JavaScript vanilla
- Backend (se necessário): Node.js
- Deploy: Vercel
- Formulário: webhook WhatsApp ou formulário nativo

## Referências Visuais
- Cores: definir paleta (sugestão: azul escuro + branco + destaque)
- Fonte: sans-serif moderna (Poppins, Inter, ou similar)
- Estilo: limpo, profissional, com animações sutis
- Responsivo: mobile-first

## Notas
- Logo e identidade visual serão adicionadas pelo usuário no final
- Conteúdo dos textos será definido pelo usuário
- Prioridade: **mobile-first**, performance, SEO básico
